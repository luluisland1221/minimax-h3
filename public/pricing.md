# MiniMax H3 Pricing

Last updated: 2026-08-07

These prices apply to minimaxh3.pro, an independent third-party MiniMax H3 video generation workspace. They are not MiniMax API prices. The live estimate shown in the Playground is authoritative if rates change.

## Generation rates

- 768P output: 25 credits per generated second
- 2K output: 40 credits per generated second
- Duration: 4–15 seconds
- Reference video: charged at the selected resolution rate for billable input seconds
- Reference images: the first five are included; each additional image costs 9 credits
